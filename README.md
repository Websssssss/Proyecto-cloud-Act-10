# Proyecto Cloud Computing - Semana 10

## Descripción del Proyecto
Aplicación web dinámica con sistema de inicio de sesión seguro, desarrollada mediante una arquitectura basada en contenedores. El proyecto cumple con los requisitos de seguridad establecidos, incluyendo el uso del algoritmo bcrypt para el hash de contraseñas y el aislamiento de credenciales mediante variables de entorno.

## Arquitectura de la Solución
* **Backend y Aplicación:** Python 3.9 (Flask)
* **Base de Datos:** PostgreSQL 17 (Instancia administrada)
* **Contenedorización:** Docker (Imagen personalizada subida a Docker Hub)
* **Estrategia de Despliegue (Opción A):** Blitz Cloud (IaaS/PaaS) con HTTPS automático.
